# 📚 EchoWord

EchoWord is a vocabulary learning mobile application built with **React Native** and **Expo**. The app helps users create their own word lists, review vocabulary, and improve their language learning experience through a simple and intuitive interface.

## ✨ Features

- 📖 Create and manage vocabulary lists
- ➕ Add new words and meanings
- 🔍 Search vocabulary
- 📱 Cross-platform mobile experience
- 🎨 Modern and user-friendly interface
- ⚡ Built with Expo for fast development

## 🛠 Tech Stack

- React Native
- Expo
- JavaScript
- Firebase

## 🚀 Installation

```bash
git clone https://github.com/enesaydnn/ExpoApp_EchoWord.git

cd ExpoApp_EchoWord

npx expo start
```
